# Warframe Relic Tracker

Track Warframe relic collections with ducat values and market prices.

## Features

- 📊 Dashboard with completion stats and ducat totals
- 🔍 Relic browser filtered by tier (Lith/Meso/Neo/Axi), vaulted status, obtained
- 💎 Detail view with drop tables, ducat values, and market prices
- ✅ Collection checklist (toggle obtained, set quantity)
- 💰 Auto-calculated ducat values from drop rarity
- 📈 Market price data from Warframe Market API

## Tech Stack

- **Backend:** Python + FastAPI
- **Database:** SQLite
- **Frontend:** 2005 Professional CSS (Verdana/Tahoma, steel blue, beveled borders)
- **Data Sources:** WFCD Drop Data + Warframe Market API
- **Packaging:** PyInstaller + Inno Setup installer
